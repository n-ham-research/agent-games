## 2. Deviation-preserving representation progress

P17-T1 in phase17-representations.md extends read-once tasks to monotone
formulas with r REPEATED WORKERS: an exact full payoff/success LP, optimization
and central law recovery in2^{O(r)}poly(S,L), S=occurrence size. Each node
stores actual value, the r single-worker counterfactual values and actual
sensitivity. Ordinary leaves share inputs across all worlds; repeated leaf
values are fixed by their common actual bit. Repeated-worker IC comes from
root differences. Inequalities sum across hidden actual repeated-bit cells,
which are not publicly disclosed. This is FPT in the number repeated, NOT
in maximum occurrences, and not a new universal junction-tree theorem.

P17-T2 proves a specified global terminal-summary architecture can require
2^m states even for a read-once task with an O(m) local LP. Thus a small
terminal summary is sufficient but not necessary for compact exact regions.
This is a distinguishability result for that architecture, not an arbitrary
symbolic-representation or LP lower bound.

## 3. New tractability and exact LP lower bound

P17-X in phase17-originality.md gives an unconditional boundary. On2m vertices
of a complete graph, each edge-worker covers its endpoints. Success means
all vertices covered, a monotone formula with every worker appearing exactly
TWICE and O(N) gates, N=binom(2m,2). At B1,c_i1/2, for every fixed conditional
margin0<=delta<=1/2, the full success/ALL-payoff region has a perfect-matching
face: s=1 and expected work=m. Every matching profile is delta-obedient.
The affine coordinate map recovers matching incidence marginals from payoffs.

Rothvoss1311.2369v4 Theorem1 therefore implies exact LP extension size
2^{Omega(sqrt N)}. The deep lower bound is EXTERNAL PRIOR, not re-proved here;
our candidate is the restricted payoff-face transfer. Ahmadinejad et al.
already use matching geometry to distinguish compact LP from efficient game
oracles. This is not the first game-theoretic use of Rothvoss.

Crucial limits: the face already appears in NONOBEDIENT task-feasible geometry.
This does not isolate an incentive-caused extra compression cost. Nor is it
runtime hardness, a fixed-protected-k lower bound, or an approximation/SDP
barrier. Read-twice syntax can defeat a full exact LP while few repeated
workers still permit the FPT construction. Those are different parameters.

## 4. Multiple independent incentive constraints in disclosure

phase17-disclosure.md gives a polynomial N²-variable LP for randomized public
Bayes guessing with arbitrarily many EXPLICIT obedience rows. Messages with
the same optimal guess merge safely and preserve the objective. This is an
application of established direct-decision persuasion/LP methodology, actually
compared with Dughmi–Xu, not a new generic information-design theorem.
A three-volunteer example has two independent tight rows; scalar aggregation
admits unsafe channels. Limited alphabets give an XP enumeration and a k/N
garbling guarantee, not a new FPT claim.

The note also investigates joint recommendation redesign: when state has no
payoff role and constraints concern only unconditional action outcomes, an
existing feasible law can be chosen state-independent and full public state
revelation becomes safe. Thus old fixed-law disclosure difficulty need not
survive joint redesign. State-only independence can make exact joint-law
feasibility nonconvex; no general joint-design hardness follows just from that.
An unresolved alphabet comparison in a privacy source is disclosed, not called
an error or used as evidence of a new theorem.

## 5. Serious decentralized equilibrium-selection exploration

phase17-decentralized.md separates honest local computation from strategic
implementation. Read-once min-cost selection is local AND/OR DP with O(n)
messages and a strict successful terminal pure NE. It assumes honest inputs/
execution and is not an equilibrium of the communication game by itself.

For two private positive-cost volunteers, no transfers/verification and an
ex-post protocol ALWAYS succeeding with EXACTLY ONE worker, whole-protocol
type imitation forces winner probabilities to ignore both costs. A fixed
uniform role lottery has sharp worst-case total-cost approximation
(h+l)/(2l); a disjoint-pair extension and approximate-IC bound are supplied.
These are scoped established-method consequences, not a general impossibility
when failure, redundant work, costly messages or future tasks are permitted.
An anonymous fair-bit election works honestly but a worker can profitably
always send0. Terminal strict equilibrium does not cure message manipulation.
No decentralized learning/convergence theorem was established this phase.

## 6. Resource-bounded substitution: substantive stopping decision

No genuinely new approximate synthesis guarantee emerged. The investigation
explicitly refuses to repackage the old TV regret bound with a default-policy
prediction error: a deviator may steer to untested histories. Existing observer/
INDEX results are preserved. Next worthwhile work needs an efficiently checkable
UNIFORM error guarantee over budgeted deviations or a useful interacting arena
class. This is a deliberate redirection, not a claimed new substitution theorem.
